# LPPP Homes mod

A /home mod developed for use on my private long-running community server.

Despite other Home mods being available, the biggest issue usually is lack of up-to-date versions. Since the Homes mod was usually the major slowdown, to prevent stalling server updates to new Game Drop versions I decided to write my own mod and learn Fabric mod development in the process.

For now, the basic functionality is there + some moderator features. I'll most probably develop it further as long as the server is alive (which is probably going to be a while, at least at the current point in time).
